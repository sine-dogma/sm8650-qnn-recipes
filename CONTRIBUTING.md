# Contributing

Keep conversion local, pin external assets, and separate model adapters from the SM8650 target and quantization recipes. Run the source tests and describe any actual SDK or device checks with the SDK build and host platform.

Do not commit credentials, personal or machine-specific paths, SDK files, downloaded models, raw dataset records, calibration captures or generated binaries. Use the ignored work/output directories. Keep model and dataset licenses intact and update NOTICE when adding external materials.

Original contributions to this repository are provided under CC0-1.0. Dependencies and imported materials retain their own licenses.
